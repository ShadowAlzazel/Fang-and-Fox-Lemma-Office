The triangle that doubles

Written proof (PROOF.md)

proven in Lean, all nupstream: unformalized

Invert a sparse triangle of fractions, add up each row, and read the answers mod 2. Out comes the Feigenbaum kneading sequence, the symbolic itinerary of the logistic map at the end of the period-doubling cascade. Here is why, in four short steps, with a Lean file whose lemmas follow them.

The conjecture

OEIS A127752 (Paul Barry, 2007), offset 0:

“Row sums of inverse of number triangle A(n,k) = 1/(3n+1) if k <= n <= 2k, 0 otherwise.”

Its data begin 1, 4, 3, 7, 3, 6, 3, 10, 3, 6, 3, 9, 3, 6, 3, 13, … and the entry carries two comments:

“a(n) mod 2 is first Feigenbaum symbolic sequence A035263 (conjecture).”
“The conjecture is true at least up to 2048 first terms. (But please note the different indexing, here 0-based.)” – Antti Karttunen, Sep 29 2018

A035263 (offset 1) is “Trajectory of 1 under the morphism 0 -> 11, 1 -> 10; parity of 2-adic valuation of 2n: a(n) = A000035(A001511(n)).” So the precise claim is

$$\mathrm{A127752}(n)\equiv \mathrm{A035263}(n+1)=\nu_2\bigl(2(n+1)\bigr)\pmod 2\qquad\text{for all } n\ge 0.$$

Left to Solve lists it as oeis-a127752 (“OEIS conjectures (not formalized)”, difficulty 45). The sibling entry oeis-a127751 states the same conjecture about the triangle A127751 itself: “Row sums A127752 mod 2 are conjectured to be first Feigenbaum symbolic sequence A035263.” The theorem below covers both.

The proof

Write \(A\) for the lower-triangular matrix with \(A(n,k)=\frac1{3n+1}\) when \(k\le n\le 2k\), \(B=A^{-1}\), and \(a=B\mathbf 1\) for its row sums. The whole proof is: stop inverting, and look at what \(a\) has to satisfy.

1 · Every window sums to 3n + 1

Since \(AB=I\), we get \(Aa=AB\mathbf 1=\mathbf 1\). Row \(n\) of \(A\) is the constant \(\frac1{3n+1}\) on the window \(\lceil n/2\rceil\le k\le n\) and zero elsewhere, so row \(n\) of \(Aa=\mathbf 1\) says

$$\sum_{\lceil n/2\rceil\le k\le n} a(k)=3n+1.$$

tri_mulVec_r, blockSum_r

2 · Slide the window: a doubling recursion

Going from row \(n-1\) to row \(n\), the window always gains its new top entry \(a(n)\), and loses its bottom entry \(a(\lceil (n-1)/2\rceil)\) only when \(n\) is odd. The right side grows by exactly 3. So

$$a(0)=1,\qquad a(2m+2)=3,\qquad a(2m+1)=a(m)+3.$$

That is the Lean function r, and blockSum_r proves it satisfies every window equation.

3 · Triangularity makes the solution unique

Each truncation of \(A\) is lower triangular with diagonal \(\frac1{3n+1}\ne 0\), so its determinant is a unit and \(Aa=\mathbf 1\) has exactly one solution. Hence \(a=r\), for every truncation size that contains row \(n\). In particular every \(a(n)\) is a positive integer, which is not obvious from a matrix of fractions.

tri_lower, tri_det_isUnit, rowSum_inv_tri, a127752_eq_r

4 · Mod 2 it is copy-and-flip

Mod 2 the recursion reads \(a(2m)\equiv 1\) and \(a(2m+1)\equiv 1+a(m)\). Each step of \(m\mapsto 2m+1\), which is \(n+1\mapsto 2(n+1)\), flips the bit; an odd \(n+1\) resets it to 1. Counting the flips is counting factors of 2:

$$a(n)\equiv 1+\nu_2(n+1)=\nu_2\bigl(2(n+1)\bigr)\pmod 2.$$

This is Cloitre's rule for the period-doubling sequence, “concatenate, then change the last term”, read backwards. r_mod_two, and the headline a127752_mod_two.

Closed form, for free

Unwinding \(a(2m+1)=a(m)+3\) down to an even index or to 0 gives

$$a(n)=\begin{cases}3k+1 & n=2^k-1,\\ 3\,\nu_2(n+1)+3 & \text{otherwise.}\end{cases}$$

Checked numerically for \(n<10^6\) in check.py; not stated in Lean, since the parity theorem does not need it.

The Black Swan link

ShadowAlzazel's Black Swan notes (CALLBACKS_AND_NEXT_STEPS.md §4) checked that the kneading sequence at the Feigenbaum accumulation point, RLRRRLRLRLRRRLRR…, is the ruler function \(\nu_2(j)\) mod 2 for 1,023 symbols of the period-1,024 superstable orbit, with R meaning “\(\nu_2(j)\) even”. The proof above shows why a matrix built from \(1/(3n+1)\) lands on the same word: the window \([\lceil n/2\rceil, n]\) is a halving, so its sliding produces the recursion \(a(2m+1)=a(m)+\text{const}\). That is a renormalization step, one period doubling per factor of 2, the same self-similarity as \(g(x)=\alpha\,g(g(x/\alpha))\). The value \(3n+1\) only fixes the constant 3; any odd constant would give the same parity pattern. With \(2n+1\) in place of \(3n+1\) the constant is 2, and the parity is 1 exactly at \(n=2^k-1\): the Fredholm–Rueppel sequence, which is the conjecture on oeis-a127750. That sibling is checked numerically here (80 terms) but not yet in Lean.

The Lean half

The complete file is A127752.lean (Lean 4 + Mathlib v4.33.1, no extra imports). Its definitions are written to be read against the OEIS entry:

/-- The OEIS triangle truncated to indices `0..N-1`:
`A(n,k) = 1/(3n+1)` if `k ≤ n ≤ 2k`, and `0` otherwise. -/
def tri (N : ℕ) : Matrix (Fin N) (Fin N) ℚ :=
  fun n k => if (k : ℕ) ≤ n ∧ (n : ℕ) ≤ 2 * k then 1 / (3 * (n : ℚ) + 1) else 0

noncomputable def a127752 (n : ℕ) : ℚ := ∑ k, (tri (n + 1))⁻¹ (Fin.last n) k

/-- A035263 (offset 1), from the Formula section of OEIS A035263: parity of the 2-adic valuation of `2n`, i.e. `A000035(A001511(n))`. -/
def A035263 (n : ℕ) : ℕ := padicValNat 2 (2 * n) % 2

/-- **OEIS A127752 conjecture.** `a(n)` is an integer and `a(n) mod 2 = A035263(n+1)`
(A127752 is 0-based, A035263 is 1-based). -/
theorem a127752_mod_two (n : ℕ) :
    ∃ m : ℤ, a127752 n = m ∧ m % 2 = (A035263 (n + 1) : ℤ) := …

Honest caveats

What exactly is proved

A035263 is defined via ν₂, from the Formula section of OEIS A035263 (A000035(A001511(n))), not via the morphism 0 → 11, 1 → 10 in its name. The equivalence of the two descriptions is classical but not formalized here; the 34-term guard only checks they agree at the start.

a(n) uses the (n+1)×(n+1) truncation of the infinite triangle, with Mathlib's matrix inverse. The lemma rowSum_inv_tri shows every larger truncation gives the same row sum, so the choice does not matter. We proved the determinant is a unit, so Mathlib's convention that a singular matrix has inverse 0 never applies.

Index shift: A127752 is 0-based and A035263 is 1-based, so the theorem pairs A127752(n) with A035263(n+1). The OEIS data confirm this is the intended shift.

Not an upstream credit match. The Left to Solve entry is “unformalized”: google-deepmind/formal-conjectures (at 9097e2f) has no Lean statement for A127752 yet, so this is our own formalization plus a proof, not a solve of an existing statement. Upstream may choose different conventions (for example a function ℕ → ℤ).

It covers oeis-a127751 too, whose conjecture is the same statement about the row sums of A127751.
